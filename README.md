# Phone Addiction Dataset Analysis

## 1. Project Overview

This is a beginner-friendly data analysis project created for learning and practice. The goal is to explore a phone addiction dataset, understand patterns in phone usage, and investigate how phone usage may relate to sleep, academic performance, and mental well-being.

## 2. Dataset Description

The dataset contains information about individuals' phone usage habits, lifestyle, and well-being. It includes features such as:

- `Age` – The age of the individual.
- `Gender` – The gender of the individual.
- `Sleep_Hours` – The number of hours spent sleeping.
- `Academic_Performance` – A measure of academic performance.
- `Social_Interactions` – Information about social interactions.
- `Exercise_Hours` – The number of hours spent exercising.
- `Anxiety_Level` – An indicator of anxiety level.
- `Depression_Level` – An indicator of depression level.
- `Self_Esteem` – A measure of self-esteem.
- `Screen_Time_Before_Bed` – Time spent using a screen before sleeping.
- `Phone_Checks_Per_Day` – The number of times the phone is checked daily.
- `Apps_Used_Daily` – The number of applications used daily.
- `Time_on_Social_Media` – Time spent on social media.
- `Time_on_Gaming` – Time spent gaming.
- `Addiction_Level` – An indicator of phone addiction level.

The dataset is used for educational purposes. Its source and the definitions of individual variables should be verified from the original dataset documentation.

## 3. Problem Statement

The primary objective of this project is to explore phone usage patterns and investigate whether phone usage is associated with sleep duration, academic performance, and self-esteem.

The analysis will aim to answer questions such as:

- How is phone addiction distributed across individuals?
- Is screen time before bed associated with sleep duration?
- Is phone addiction associated with academic performance?
- How does self-esteem vary across different levels of phone addiction?
- Which phone usage habits show the strongest relationships with addiction level?

This project focuses on exploratory data analysis and identifying patterns. Any observed relationships will not automatically be interpreted as evidence of causation.

## 4. Project Objectives

- Inspect and understand the dataset.
- Identify and handle missing values and duplicate records.
- Clean inconsistent data types and categorical values.
- Perform exploratory data analysis (EDA).
- Create visualizations to identify patterns and relationships.
- Summarize findings and draw evidence-based conclusions.

## 5. Python Libraries

The following Python libraries will be used:

- **pandas** – For loading, cleaning, and manipulating tabular data.
- **numpy** – For numerical operations and calculations.
- **matplotlib** – For creating data visualizations.
- **seaborn** – For statistical plots and exploring relationships between variables.
- **scikit-learn** – For optional introductory machine learning experiments.

By completing this project, I aim to improve my practical skills in Python, data cleaning, exploratory data analysis, data visualization, and interpreting data-driven findings. The project is intended for learning and does not aim to provide medical or clinical conclusions about phone addiction.
